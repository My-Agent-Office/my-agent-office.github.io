사무실을 더 잘 쓰는 법

시작하기

내려받아 열면 끝. 따로 설정할 것이 없어요.

설치
  • dmg를 열고 앱을 응용 프로그램 폴더로 끌어 놓기
  • 처음 열 때 막히면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기
  • 새 버전이 나오면 앱이 알려 주고 앱 안에서 바로 업데이트
처음 화면
  • GitHub 또는 Google 계정으로 로그인
  • 혼자 쓰기: 기다리지 않고 바로 내 1인 사무실
  • 내 사무실 만들기: 팀 사무실을 신청하고 열리면 참가자 부르기
  • 다른 사무실로 들어가기: 받은 사무실 주소로 참가
하루 시작과 끝
  • 맨 위 Clock in 을 누르면 출근, 다시 누르면 퇴근
  • 내 Claude Code · Codex 세션은 알아서 책상에 앉아요
  • 창을 닫아도 메뉴바에 남아 있고, 완전히 끄려면 ⌘Q
사무실 · 책상

세션 하나가 책상 하나. 책상만 봐도, 눌러 봐도 알 수 있어요.

상태 읽기
작업 중

바쁠수록 불이 커져요

답변 대기

? 가 뜨고 맥 알림이 와요

멈춤

오래 멈추면 이름표 앞 네모가 빨개져요

  • 이름표 앞 네모: 초록 작업 중 · 노랑 대기 · 회색 쉬는 중 · 빨강 멈춤 · 어두운 회색 자리 비움
책상을 누르면
  • 브랜치 · PR · 지금 하는 일
  • 서브에이전트마다 맡은 일 · 걸린 시간 · 만든 파일
  • 에이전트가 만든 파일 열기, 세션이 띄운 localhost 열기
  • 책상 모니터에서 바로 터미널, 세션 이어서 하기
  • 결과물을 팀에 공개하거나 게시판에 올리기
지난 세션 · 숨기기
  • Sessions → 지난 세션: 끝난 세션을 검색하고 ★ 로 보관, 그대로 이어서 하기
  • 개인 용무 세션은 책상 우클릭 → 이 자리 숨기기 (팀에도 안 보여요)
  • 다시 보이게 하려면 설정 → 화면 → 숨긴 자리
  • People 을 누르면 사람마다 한 줄로 책상을 늘어놓고 봐요
내 자리 꾸미기
  • 소품 가게에서 산 소품을 끌어서 책상 위 원하는 자리에
  • 책상에 안 올린 소품 · 훈장 · 스티커는 Items 서랍에
  • Status 로 내 캐릭터 머리 위에 한마디
  • 자리를 비울 땐 출입구 발판을 눌러 외출 표시
팀

멀리 있어도 한 사무실에서 일하는 것처럼.

같이 일하기
  • Chat 으로 1:1 대화, 회의실 · 탕비실로 부르기
  • 동료 책상에 칭찬 스티커 붙이기
  • 팀이 여럿이면 방이 나뉘고, 설정에서 우리 팀 방만 보기
  • 맨 위 한 줄로 누가 출근 · 퇴근했는지
게시판
  • 공지 · 사진(여러 장) · 투표 글
  • 댓글과 리액션, 새 글은 맥 알림으로
  • 책상의 결과물을 그대로 올려 공유
근무 기록
  • Log: 사람별 출퇴근 · 작업 시간을 날짜별로
  • 퇴근할 때 남긴 쪽지와 그날 한 일도 함께
Figma · Notion
  • Figma 앱에서 작업 중이면 옆에 Figma 책상이 생겨요
  • 방장이 Notion 보드를 연결하면 진행 중 티켓이 책상 위에
회의

회의실에 들어가면 바로 회의가 시작돼요.

화상 · 음성
  • 화면 공유, 마이크 · 스피커 고르기
  • 말하는 사람의 채팅은 자막으로
  • 받아 적기를 켜면 말을 글로 남기고, 끝나면 내 Claude Code · Codex 가 요약
  • 앱 없는 사람은 게스트 링크로 브라우저에서 참여
보드 · 플래닝 포커
  • 포스트잇으로 아이디어 모으고 끌어서 묶기
  • 플래닝 포커: 각자 카드를 고르고 한꺼번에 공개
  • 회의 주제 · 참가자 · 정한 점수는 회의 기록에
탕비실

쉬는 시간엔 탕비실로. 사무실 금고로 열 수 있어요.

오락기
  • 코인 하나로 한 판, 둘이 같이 하는 게임도
  • 게임마다 사무실 순위표
크레인
  • 캡슐을 집어 서랍에 모으기
  • 시즌마다 상품이 바뀌어요
  • 가끔 기계가 들뜨는 시간이 있어요
럭키박스 · 운세
  • 하루 한 번 오늘의 운세
  • 운이 좋은 날엔 다른 곳에서도 좋은 일이
사무실 고양이
  • 쓰다듬어 주면 좋아해요. 너무 많이는 말고요
  • 고양이도 고마운 사람을 기억해요
업적 · 코인

일하고, 같이 놀고, 사무실을 챙기면 쌓여요.

조건은 비밀. 이름과 한 줄이 힌트예요.
업적
일반희귀영웅전설
  • 받은 업적은 Items 서랍에, 같은 업적은 숫자로 쌓여요
  • 방장은 사무실 업적 현황을 한눈에
코인은 이럴 때
코인 쓰는 곳
  • 오락기 한 판 · 크레인
  • 소품 가게의 소품과 특별 소품
  • 사무실 금고에 모아 회의실 · 탕비실 · 게시판 열기
알아 두면 좋은 것
  • 지갑이 가득 차면 더 안 쌓여요. 틈틈이 쓰기
  • 서랍의 코인을 누르면 어디서 받았는지 기록
설정

맨 위 Settings. 바꾸면 바로 반영돼요.

화면
  • 보여 줄 세션 기간 · 배율
  • 자리에 적을 글자: 폴더 · 세션 제목 · 브랜치 · PR 번호
  • 책상에 올릴 산출물 폴더 추가
  • 숨긴 자리 다시 보이기
알림
  • 답변 대기 · 게시판 새 글 · 1:1 메시지 알림
  • Dock 숫자, 메뉴바 빨간 숫자
  • 점심 알림, 뻐꾸기 시계 간격
앱
  • 맥 로그인하면 자동으로 열기
  • 메뉴바 아이콘 켜고 끄기
  • 새 버전 알림 · 피드백 보내기
방장 탭

  • 방장에게만 보여요
